# Amelia Earhart Tribute _(tribute-page)_

A small HTML/CSS coursework page about aviator Amelia Earhart.

## Background

This is an early front-end exercise focused on semantic page structure, responsive images, typography, and external-source linking.

## Install

```bash
git clone https://github.com/ameliaeckard/tribute-page.git
cd tribute-page
python -m http.server 8000
```

## Usage

Open `http://localhost:8000/main.html` to view the page.
